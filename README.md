# Red Trail Dyrnwyn (中文簡介在下面)

## AI Disclosure:

> All code in this mod was generated by AI. However, I have tested it in-game and confirmed that the mod works as intended.

## Feature

A simple client-side mod that replaces the white trail generated when attacking with Dyrnwyn with a fiery red trail.

## Installation

### Mod Manager (Recommended):

On the mod page( https://thunderstore.io/c/valheim/p/SmoothBrainedOrganism/RedTrailDyrnwyn/ ), click Install with App to download and install the mod using Thunderstore Mod Manager.

### Manual Installation:

On the mod page( https://thunderstore.io/c/valheim/p/SmoothBrainedOrganism/RedTrailDyrnwyn/ ), click Download. Make sure BepInExPack Valheim ( https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/ ) is already installed, then extract RedTrailDyrnwyn.dll from the downloaded archive and place it in the BepInEx/plugins/ folder inside your game directory.

## How It Works

This mod replaces the trail material generated when attacking with Dyrnwyn. Instead of using the default white club_trail shared by all weapons, it uses red_trail, another material already included in Valheim.

> Fun Fact: Interestingly, red_trail was actually the trail material used by the old version of Dyrnwyn (prefab name: SwordIronFire).

> Both the old Dyrnwyn and red_trail are still present in the game files. So why did the new Dyrnwyn lose a feature that the old version had, even though the red_trail asset is still right there in the game?
